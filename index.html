Family Photo Tagger
Tag faces in old photos and save names alongside the originals in Google Drive. One-time setup, then share the page with anyone.
Connect Google Drive
Go to console.cloud.google.com → new project → enable Google Drive API.
Go to OAuth consent screen → External. Add all users under Test users.
Go to Credentials → Create → OAuth 2.0 Client ID → Web application. Add your hosting URL under Authorised JavaScript origins. Copy the Client ID.
Paste your key
Your key is stored only in this browser. Photos never leave your Google account.
